Organisms

This directory contains complex UI sections composed of molecules and atoms (e.g., header, footer, hero).

When creating an organism:
- Start the file with: "This component is an Organism because..."
- Use semantic containers (`header`, `main`, `nav`, `footer`, `section`).
- Prefer CSS Grid for page-level layout; ensure all widths are responsive (use `max-width` rather than fixed `width`).
- Enforce accessibility and keyboard navigation.

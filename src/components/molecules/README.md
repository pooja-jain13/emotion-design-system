Molecules

This directory contains groups of atoms that work together (e.g., a form field made of label + input + hint).

When creating a molecule:
- Start the file with: "This component is a Molecule because..."
- Use semantic wrappers (`fieldset`, `label`, etc.) where appropriate.
- Follow BEM for class names; reference atoms' BEM blocks when composing.
- Prefer Flexbox for internal layout; ensure responsiveness.
